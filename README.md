# Thesis Desk

Téléchargez la dernière version dans **Releases** (fichier `.dmg`, Mac Apple Silicon : M1, M2, M3, M4).

## Installation

1. Ouvrez le fichier `.dmg` téléchargé, puis glissez **Thesis Desk** dans le dossier **Applications**.
2. Ouvrez Thesis Desk depuis Applications. macOS affiche « Apple n'a pas pu confirmer… » : cliquez sur **Terminé** (jamais sur « Placer dans la corbeille »).
3. Ouvrez **Réglages Système > Confidentialité et sécurité**, descendez jusqu'à « Thesis Desk a été bloqué » et cliquez sur **Ouvrir quand même**, puis confirmez avec votre mot de passe ou Touch ID.
4. L'application s'ouvre et vous guide pas à pas.

Cette étape n'est nécessaire qu'une seule fois.
